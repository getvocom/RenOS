The governed session

A record a stranger can read

Each task is one governed session: who ran it, on which model, under which policy, with what outcome.

  • Plain-language summary of what happened and why that model was chosen.
  • Step-by-step timeline from request to accepted result.
  • Tamper-evident chain so records can be verified later.

In plain language

Kevin asked for a rent-increase notice. Because it involved confidential tenant data, policy required an approved frontier model. Claude ran it in 4.2 seconds. Kevin accepted it. No overrides.
