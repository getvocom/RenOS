Key Ideas

What Makes Credits Predictable

Credits Track Real Usage

Each task is charged for the tokens it actually used, at its model's published rate.

A Hold Before Anything Runs

The estimated cost is reserved first, so a task never starts without budget to finish.

Cost Lives in the Record

Every task's credits sit next to the model and policy that chose it.

Work Pauses at the Cap

Teams can't overspend. Owners approve increases, and agent runs stop at their ceiling.

Frequently Asked Questions

What Is a RenOS Credit?

A credit is the unit RenOS uses for model usage. Each task spends credits based on the tokens it actually used. See RenOS pricing for plans.

Why Does RenOS Place a Hold Before a Task Runs?

The hold reserves the estimated cost so the task can finish within budget. When it's done, RenOS charges actual usage and releases the rest.

What Happens When a Team Runs Out of Budget?

Work pauses instead of overspending. The person can switch to a lower-cost model or ask the budget owner to approve a one-time increase.

Can an Agent Run up a Big Bill?

No. Each agent task has a hard ceiling, and the run stops when it reaches it.

Where Can We See What Each Task Cost?

In the admin view and in every audit entry. See the admin dashboard.

Who Can Top up Credits?

Org admins, by card or by invoice on Enterprise. Auto top-up can refill the balance when it runs low.
